Documentation & Android Guide

ANDROID OPTIMIZATION

How to Save PTY Terminal from Auto-Kill

Android OS aggressively terminates background apps, web browser processes, and PTY/Termux sessions to free memory or save battery. Follow these step-by-step solutions to prevent Android from killing your terminal session:

1
Disable Battery Optimization (Unrestricted Battery)

Go to Android Settings > Apps > Chrome / Browser > Battery > select Unrestricted (or "Don't optimize"). This prevents the OS from suspending background socket connections when switching tabs or turning off the screen.

2
Lock App in Recent Apps Switcher

Open Android's Recent Apps / Overview screen, tap or long-press the browser icon on top of the preview card, and select Lock or Keep open. This protects the process from Android's RAM cleaner.

3
Termux Background Wake Lock (If Hosting locally on Termux)

If running your SSH host on Termux, execute termux-wake-lock in Termux shell, or tap Acquire Wake-Lock from the Termux notification bar. This keeps CPU awake during background execution.

4
Disable Android 12/13+ Phantom Process Killer

On Android 12/13+, Android kills child processes that consume excess CPU. Disable this restriction via ADB:
adb shell device_config put activity_manager max_phantom_processes 2147483647 or turn off "Child process restrictions" in Android Developer Options.

5
Always Use Tmux or Screen for Zero-Data-Loss Persistence

Launch tmux or screen on your server or Termux. Even if your phone loses cellular signal or Android kills the web browser tab, your remote terminal commands, build processes, and scripts keep running in background without interruption.

CAPACITOR & GITHUB ACTIONS APK

Build Android APK on GitHub Actions

This app is configured with Capacitor and includes an automated .github/workflows/android-apk.yml workflow.

1
Push Repository to GitHub

Push or export this project repository to your GitHub account.

2
Automatic GitHub Actions Build

GitHub Actions will automatically run the build workflow using Java 17 and Node 22 to generate your Android APK.

3
Download your APK

Go to the Actions tab in your GitHub repository, tap the latest workflow run, and download the SSH-PTY-Terminal-debug artifact containing your app-debug.apk.

ANDROID TROUBLESHOOTING GUIDE

Fix Guide for Android Users

Draggable Floating Find Bar

Tap and drag the ⋮⋮ handle on the Find popup with your finger. You can position the search bar anywhere on screen. It is automatically constrained so it will never slide off the screen edges on mobile devices.

On-Screen Virtual Keyboard Issues & Fixes

If Android soft keyboard auto-correct breaks terminal commands or adds trailing spaces, turn off text prediction for terminal inputs, or install Hacker's Keyboard or Unexpected Keyboard from Google Play Store for native Esc, Tab, Ctrl, and arrow key support.

Terminal Quick Toolbar Keys

Use the top action toolbar in Terminal view to send Ctrl+C (Interrupt), Clear (Ctrl+L), Esc, and Tab with a single tap without needing complex mobile keyboard gestures.

Network Drops & Automatic Token Reconnection

When toggling between Wi-Fi and 4G/5G mobile data, network addresses change. The terminal automatically uses local session token persistence to reconnect your PTY channel without losing your settings.

Word Wrap & Mobile Screen Density

If long output lines stretch horizontally on mobile screens, enable Word Wrap in the Config tab, or tap A- / A+ on the terminal toolbar to fit more text on narrow smartphone screens.
